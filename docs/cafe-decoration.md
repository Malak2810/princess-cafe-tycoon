# Café Decoration Feature

## Objective
Allow players to personalize the café interior.

## Main features
- Choose furniture and decorative items.
- Arrange tables, chairs and decorations.
- Preview the café before confirming changes.
- Save the selected layout.

## Acceptance criteria
- The player can select decorative items.
- The player can arrange items in the café.
- The player can preview and save the layout.
